# FBA仓点派送分析

输入文件、批次清洗和出库日期归期保持不变。功能二在“全部”或“FBA”模式下，优先输出两张新表：

- **FBA仓点分析**：按发货仓、出库统计周期、FBA仓点汇总全部有效货量，展示方式方数、方式占比、平均每方成本、有效成本方数及覆盖率。
- **FBA派送方式分析**：每个仓点下按整车大车卡板、整车大车地板、整车小车、多卸、LTL分别列行。供应商方数、比例、整车成本、每方成本及成本覆盖率各放在一个单元格，按方数降序列出全部供应商。未知/冲突供应商保留其货量及分母，不归属其他供应商。

新表中的每方均价是**有效批次的每方单价的算术平均**；整车均价是先合并完整车次的批次成本，再对有效整车价格求平均。运营成本使用含装车费的派送成本；供应商成本优先使用原始派送成本，缺失或非数值时逐行回退，并标注回退批次数。原始成本为零时不回退。

货量始终累积，不因缺成本、低装载或缺真实车次而被删除。运营价格沿用原始成本大于零的筛选；有原始成本列但本行缺失时，不作为有效运营价格样本。有效成本方数除以总货量得到成本覆盖率，避免把缺成本货量当作免费运输。

普通派送的共享均值门槛为大车地板 **≥60 CBM**、大车卡板 **≥40 CBM**，在完整车次体积上判断；小车、LTL没有这两个门槛。共享规则同时适用于原普通派送成本/装载平均值与P80，不改变货量。黄金批次独立的地板80–120、卡板40–80范围不变。

功能一新增完整车次的批次目的地上下文字段，经过Excel保存后仍可使用。功能二在匹配后更新已出现批次的目的地，保留未出现的其他卸点证据，然后按出库周期与目的地展示。只有最终FTL车次按不同目的地判断多卸；同车次多个批次同一目的地视为整车。LTL归类沿用已有运输类型清洗的最终结果。

旧文件仍可读取。缺少完整目的地证据时进入“待确认”，不猜测整车类别；车次在当前周期只出现部分批次时，保留本期方数和可用每方价格，不生成部分车次的整车价格。同车次供应商不唯一时不生成单一供应商的整车报价。已有批次基础成本不会按车次重复分摊，仓内地板装车费仍按精确份额合计每车200美元。

原“每方价格参考”和“分类型价格参考”作为既有价格参考保留；其中总成本/总方数的参考价与新表的批次平均单价是不同统计量，原单批次整车价格样本也保留。查看此次五种派送方式及供应商结构时使用两张新表。

“派送时效”仅输出已识别FBA仓点与FBX平台仓，保留现有有效FTL批次、缺车次/日期/异常时效/里外备注排除规则，以及有效方数加权平均和P80。调拨数据、干线数据与黄金批次的计算和输出结构不变。

验证：`python -m unittest discover`。回归覆盖原始文件→功能一→Excel→功能二→Excel、全部/FBA/FBX分支、方数占比、批次平均与总体比值差异、同目的地合车、混合FBA/FBX多卸、LTL、60/40边界、未知供应商、跨月部分车次、两套成本来源，以及受保护报表结果一致性。
