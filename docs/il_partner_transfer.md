# LA 至 IL 合作仓调拨

用户指定地址：610 Supreme Dr. Bensenville, IL 60106。

该地址是合作仓，目的地分类为 FBX。业务归为合作仓调拨，在功能二「调拨数据」显示目标仓「IL合作仓」、线路「LA-IL」。原 LA/NJ/SAV/DAL 盈仓调拨分类不变。

## 识别

- 仅扩展 LA 发货仓，不根据本次需求推断其他始发仓路线。
- 当前批次的调入仓、目的地、标准地址或备注明确包含 IL合作仓（忽略英文大小写，允许 IL 与合作仓之间空格），即可认定。
- 地址匹配要求门牌 610、街道 Supreme、Dr 或 Drive，并且 Bensenville 或 60106 至少一个吻合。存在其他五位邮编时拒绝地址匹配。裸邮编、IL 州、Bensenville 城市、相似门牌均不够。
- 新功能一输出还保留调拨目标代码 IL 和批次目的仓点 IL合作仓，功能二可以稳定重识别。
- 不读取车次号、批次号或同车次合并备注作为 IL 证据，不将调拨目的地传播给同车的其他批次。
- 调入仓字段维持原优先级。同批次不同记录出现多个调拨目标时，继续转入现有冲突审核。

## 数量与价格

- 物理批次只保留一行。主产品类型、系统产品类型和 FBA/FBX 为 FBX；批次目的地类型为 FBX平台仓。平台和仓点显示为 IL合作仓，地址固定为用户指定地址，州 IL，邮编 60106。
- 货量、平台仓报表和调拨表从同一批次独立汇总，不复制批次，也不把 FBA 同车批次的量算给合作仓。不同报表是分析视图，不能相加当作总量。
- 调拨数据沿用 FTL 规则。LTL 保留在 FBX 分析，但不作为 FTL 调拨整车样本。缺少车次的有效 FTL 货量保留，不计发车数、整车或每方价格样本。
- 仍按批次出库时间归周/月。每车价、每方价及有效样本筛选沿用现有调拨口径。
- 总成本、平均整车价使用含地板装车费的派送成本；供应商平均整车价及各供应商成本明细使用原始承运商成本（缺失才回退），费用不重复追加。
- 旧文件若已丢失批次地址与 IL合作仓标记，仅剩 IL/60106 或同车备注，不能可靠自动补认；需使用保留本批次证据的数据重新运行功能一。

## 验证

覆盖完整功能一到功能二及 Excel 导出、同车 FBA 保留、同批次目标冲突、同邮编其他地址排除、缺车次与 LTL、重复运行费用不重加、人工匹配后目的地与邮编一致，以及周/月归期。
