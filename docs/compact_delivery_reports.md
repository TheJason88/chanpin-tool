# 派送二精简导出

业务计算仍生成原始统计结果；`delivery_report_export.build_delivery_exports` 仅整理展示，输出两份 Excel。

业务报告按以下顺序最多保留八张非空表：派送总览、FBA仓点总览、FBA派送方式分析、FBX仓点总览、分类价格参考、调拨数据、干线数据、黄金标准数据。

仓点总览按仓库、统计周期和仓点合并货量、排名、供应商比例、价格参考和时效；FBX 额外以平台名称区分。合并要求键唯一，避免重复匹配放大货量。仓点折算发车数能唯一归属时移入仓点总览，跨平台同名等不能唯一归属的分布保留在派送总览。总览的比例和分布集中在同一格，真实总发车数继续按原口径展示。

批次平均每方成本与有效总成本/总方数分别展示。分类价格参考保留单批次整车均价、P80和装载指标；FBA派送方式分析继续允许同目的地多批次合车。只移除直接重复的体积和整车价格别名。调拨、干线、黄金标准和供应商计算结果不改。

审核明细保留原名工作表：派送二_匹配后批次数据、派送二_车次汇总核对、邮编异常审核；区域与干线规则合并为规则说明。补录后上传审核文件至5A。旧版完整报告和派送一结果继续兼容；误传精简业务报告时明确提示使用审核文件。两个下载通过会话状态保留，下载一份后仍可下载另一份。

验证：`python -m unittest discover -q`。专项覆盖合并前后数值、双成本口径、平台与周期隔离、重复键保护、分数车份额、Excel导出和邮编补录回传。
